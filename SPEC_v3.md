# v3 — Deepen

> **Goal:** Post-validation, post-monetization. The bet has paid off; now the work is broadening the surface area and serving deeper use cases.

> **Prerequisites:** All v2 acceptance criteria must pass before any v3 work begins.

## 1. What's IN v3

- Office format ingestion (DOCX, PPTX, XLSX)
- Media format ingestion (audio files, video files, GLB/GLTF 3D models)
- Collaboration (shared editor access between users)
- Portfolio analytics dashboard for users (who's viewing, what's popular, privacy-respecting)
- A/B testing for portfolio variants
- Multi-language support
- API for programmatic portfolio generation
- White-label option for agencies
- Template marketplace (community-created templates)
- Grove/Heartwood account integration (if author still wants this)
- Aspen subpage transfer (if relevant)

## 2. v3 Acceptance Criteria

These are deliberately less prescriptive — by v3, the team (or solo author) should have enough product intuition to set their own gates.

- Sustainable monthly revenue (covers a full-time salary at minimum).
- Feature requests in v3 are validated by paying customers, not assumed.
- The product still has a coherent identity (no Wix-style feature sprawl).
